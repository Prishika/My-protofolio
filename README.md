# Rishika Pamanji - Portfolio

Prepared for https://github.com/Prishika/rishikapamanji

Includes the photo banner, sidebar navigation, projects, research, experience, education, skills, publications, downloadable CV, and GitHub, LinkedIn, and Google Scholar links.

## Put your portfolio online

1. Extract this ZIP on your computer.
2. Open https://github.com/Prishika/rishikapamanji and sign in as Prishika.
3. Choose Add file > Upload files. Upload index.html, styles.css, script.js, Rishika_Pamanji_CV.pdf, and the assets folder to the repository root. Preserve unrelated repository files. Do not upload the ZIP itself.
4. Click Commit changes.
5. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, choose the branch you uploaded to (usually main), choose / (root), and Save.
6. Wait for publication to finish. Open the Visit site link in the Pages settings.

Expected address after successful publication: https://prishika.github.io/rishikapamanji/
This package has not been uploaded to GitHub or published there automatically.

The website address does not include your Gmail username. Email contact information in the original CV and site is retained.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
